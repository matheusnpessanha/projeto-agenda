# Agenda de Contatos

Sistema web para gerenciamento de contatos desenvolvido com Django.

## Funcionalidades

- Cadastro de contatos
- Edição de contatos
- Exclusão de contatos
- Pesquisa
- Paginação

## Tecnologias

- Python
- Django
- SQLite
- Bootstrap

## Executando

pip install -r requirements.txt

python manage.py migrate

python manage.py runserver
